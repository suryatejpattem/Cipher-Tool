# Encryption-Tool
A simple Python-based tool that allows you to encrypt and decrypt text using multiple cipher algorithms. This tool supports the following encryption methods:

Reversing Text
Reverses the characters of the input text.

Substitution Cipher
Encrypts and decrypts the input text by randomly substituting each character with another.

Caesar Cipher
Encrypts and decrypts text by shifting each letter by a specified number.

Vigenère Cipher
A method of encrypting text by using a keyword. Each letter in the plaintext is shifted based on the corresponding letter in the key.

Features:
Supports both encryption and decryption modes.
Provides options to process text or files.
Interactive command-line interface to choose between different ciphers and modes.
