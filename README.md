# Cipher Tool

A simple Python-based tool that allows you to encrypt and decrypt text using multiple cipher algorithms.

## Features:

- Supports both encryption and decryption modes.
- Provides options to process text or files.
- Interactive command-line interface to choose between different ciphers and modes.

## How to Use:

1. **Clone the repository**:

    ```bash
    git clone https://github.com/yourusername/cipher-tool.git
    ```

2. **Navigate to the project directory**:

    ```bash
    cd cipher-tool
    ```

3. **Run the script**:

    ```bash
    python cipher_tool.py
    ```

4. **Follow the on-screen instructions** to choose a cipher and enter the text to encrypt or decrypt.

## Requirements:

- Python 3.x
